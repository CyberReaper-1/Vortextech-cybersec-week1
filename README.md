# VortexTech Cyber Security Internship — Week 1

## Research on OWASP Top 10 Vulnerabilities

This repository contains my **Week 1 Cyber Security Internship task at VortexTech**. The task focuses on researching and documenting five OWASP Top 10 web application security vulnerabilities.

## Topics Covered

* **Security Logging and Alerting Failures**
* **Software or Data Integrity Failures**
* **Authentication Failures**
* **Cryptographic Failures**
* **Injection**

The report covers the basic concept of each vulnerability, how it can be exploited, real-world examples, and prevention/mitigation techniques.

## Objectives

* Understand common web application security risks.
* Learn how these vulnerabilities can be exploited.
* Study real-world security incidents.
* Understand basic prevention and mitigation techniques.
* Improve awareness of secure development practices.
