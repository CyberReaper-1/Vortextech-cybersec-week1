\# 🔐 VortexTech Cyber Security Internship — Week 1



\## Research on OWASP Top 10 Vulnerabilities



This repository contains my Week 1 research assignment for the \*\*VortexTech Cyber Security Internship Program\*\*.



The purpose of this assignment is to research and understand five important web application security vulnerabilities from the \*\*OWASP Top 10\*\*.



\---



\# 📌 Assignment Overview



The \*\*OWASP Top 10\*\* is one of the most widely recognized awareness documents for common web application security risks.



For this assignment, I researched five important vulnerabilities and documented their basic concepts, exploitation methods, real-world examples, and prevention techniques.



\---



\# 🎯 Objectives



The objectives of this project were to:



\* Understand common web application security vulnerabilities.

\* Learn how attackers can exploit these vulnerabilities.

\* Research real-world cybersecurity incidents.

\* Understand practical prevention and mitigation techniques.

\* Develop a stronger foundation in web application security.



\---



\# 🛡️ Vulnerabilities Covered



| # | Vulnerability                          |

| - | -------------------------------------- |

| 1 | Security Logging and Alerting Failures |

| 2 | Software or Data Integrity Failures    |

| 3 | Authentication Failures                |

| 4 | Cryptographic Failures                 |

| 5 | Injection                              |



These are the five vulnerabilities covered in the research report.



\---



\# 📚 Topics Covered



For each vulnerability, the research document includes:



\* \*\*What is it?\*\* — A simple explanation of the vulnerability.

\* \*\*How can an attacker exploit it?\*\* — Common ways the vulnerability may be abused.

\* \*\*Real-world example\*\* — A cybersecurity incident related to the vulnerability.

\* \*\*Prevention and mitigation\*\* — Practical security measures to reduce the risk.
